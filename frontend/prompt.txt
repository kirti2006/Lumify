Create a modern frontend application with React, TypeScript, and Vite for the Lumify App.
Make sure to follow these rules:

1. We will keep separate folders for architectural layers inside `src/`.
The structure should be:
components/ (Reusable UI components, mostly shadcn/ui)
pages/ or views/ (Route-level components)
services/ or api/ (API interaction, axios instances)
store/ or context/ (Global state management)
hooks/ (Custom React hooks)
lib/ or utils/ (Utility functions)
types/ (TypeScript types/interfaces)

2. Use Functional Components and Hooks exclusively. Do not use Class Components.

3. Use Vite as the build tool.

4. Styling: Use Tailwind CSS and Shadcn UI components. Ensure all custom styling uses Tailwind utility classes.

5. Routing: Use React Router (v7 or v6 conventions) for client-side routing.

6. State Management: Use React Context for simple global state (like auth), and Zustand if more complex state is required.

7. Data Fetching: Use TanStack Query (React Query) for all API calls, caching, and server state management. Use Axios as the HTTP client.

8. Form Handling: Use React Hook Form with Zod for schema validation.

9. Error Handling: Use Sonner or React Toastify for toast notifications on success/error. Centralize API error handling in an Axios interceptor to catch 401s and refresh tokens automatically.

10. Types: Keep interfaces/types strict. Use Zod to define schemas and infer types for forms and API payloads.

11. The frontend connects exclusively to the MS-1 Gateway API. Store the base URL in `.env` as `VITE_API_BASE_URL`.
